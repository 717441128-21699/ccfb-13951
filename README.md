# 网页 SSTV 收图台

在浏览器里实时接收慢扫描电视(SSTV)图像的纯前端工具。电台音频线接进声卡,图像一边接收一边逐行绘制,
**无需安装任何原生软件、运行时零第三方依赖**(仅构建期用 Vite/TypeScript)。

## 支持的模式

| 模式 | VIS | 分辨率 | 色彩 | 行周期 |
|------|-----|--------|------|--------|
| Martin 1 / Martin 2 | 44 / 40 | 320×256 | GBR | 446.6 / 228.9 ms |
| Scottie 1 / Scottie 2 | 60 / 56 | 320×256 | GBR | 428.2 / 277.7 ms |
| Robot 36 | 8 | 320×240 | YUV | 238 ms(两行一组) |
| **PD120** | 95 | 640×496 | YUV | 508.5 ms(两行一组) |

解决了老软件只认 Scottie/Martin、碰到 Robot36 和 PD120 出雪花的问题。

## 针对弱信号与活动日场景的设计

- **断续恢复不另起新图**: 以同步脉冲为锚点的行网格状态机。信号中断时按内部时钟继续推进网格,
  信号回来后用新同步脉冲做小幅相位校正(±25% 行周期),始终画在同一张图上,不会错开半行。
- **补全像素显式标记**: 断流期间缺失的像素沿用最后已知值,并在图上以红色斜纹标出;
  每行记录 `live/patched/empty` 来源,通联日志里统计补全行数。
- **无 VIS 也能猜模式**: VIS 头丢失时,基于同步脉冲宽度(4.86/9/20ms)和行间隔,
  在 10 秒窗口内打分猜测模式,UI 实时显示置信度和倒计时。
- **10dB 弱信号可出图**: 复数混频正交 FM 解调 + FIR 低通 + 带通预选 + 像素中段平均,
  同步检测带滞回容错,单个噪声毛刺不会截断脉冲。
- **自动通联日志 + ADIF**: 每收完一张自动记一条(时间、模式、SNR、补全情况),
  呼号/频率可在线补全,一键导出 `.adi` 给主流日志软件,日志持久化在 IndexedDB。
- **声卡只设一次**: 设备选择存 localStorage,刷新/重开不用重新配置。

## 架构

```
声卡 ──> AudioWorklet(重采样到12kHz) ──> 解码 Worker(后台线程)
                                              │
              带通(900-2700Hz) ─> 复数混频FM解调 ─> 同步/校准头检测
                                              │
              VIS解码 ─ 或 ─ 脉冲统计猜模式(10s窗口)
                                              │
                          行网格状态机(逐行出图/断续补全)
                                              │
              RGBA合成(补全斜纹标记) ─postMessage─> 主线程 Canvas
```

- `src/dsp/` — 重采样、IIR/FIR 滤波、正交 FM 解调、RMS/SNR 估计
- `src/sstv/modes.ts` — 全部模式时序常量(与开源实现交叉核对)
- `src/sstv/sync-detect.ts` / `vis.ts` — 同步脉冲、校准头、VIS 与模式猜测
- `src/sstv/stream-decoder.ts` — 行网格状态机(核心)
- `src/sstv/receiver.ts` — 接收链路编排 + 滚动频率历史
- `src/sstv/encoder.ts` — 测试信号编码器(相位连续)
- `src/test/channel.ts` — AWGN 噪声、断续、频偏、回声信道模拟
- `src/workers/decoder.worker.ts` — 后台解码,UI 不卡顿
- `public/worklets/capture-worklet.js` — 声卡采集与重采样

## 开发

```bash
pnpm install
pnpm dev        # 本地开发服务器
pnpm test       # 32 个单元/端到端/性能测试
pnpm build      # 类型检查 + 生产构建到 dist/
pnpm preview    # 预览生产构建
```

## 测试

测试用标准编码生成四种模式的信号,再过受控信道(加噪声/断续/频偏)闭环验证:

- **DSP 层**: 解调精度(恒音误差 <8Hz)、10dB 抖动、滤波器、重采样
- **端到端**: 四模式干净解码、10dB 出图、3 秒断续不另起新图、多次断续、垂直斜坡验证不错半行
- **模式猜测**: 脉冲统计识别、抖动鲁棒性、Scottie/Robot36 区分、VIS 解码与纠错
- **ADIF**: 字段格式、UTC 时间、空值省略、多记录导出
- **性能**: 解调 >10× 实时、完整链路 >3× 实时(Robot36 整图)、PD120 大分辨率耗时可控

浏览器内点"测试信号发生器"可在不接电台的情况下,用合成的噪声/断续信号演示完整接收流程。

## 浏览器要求

需要支持 AudioWorklet、Web Worker、IndexedDB 的现代浏览器(Chrome/Edge 90+、Firefox 90+、Safari 14.1+)。
声卡采集要求 HTTPS 或 `localhost` 环境。
